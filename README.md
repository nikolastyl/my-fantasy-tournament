Fantasy Tournament Platform
A web platform for managing amateur football tournaments and fantasy leagues based on real player performances.

Overview
Fantasy Tournament Platform is a private fantasy league system designed for amateur football tournaments.

Tournament organizers can manage teams, players, matches and statistics, while participants compete in a fantasy league using real player performances.

The application supports:

Fantasy Draft
Team Lineups
Captain Multipliers
Player Trades
Free Agent Pickups
Match Statistics Tracking
Historical Data Tracking
Fantasy Rankings
