# User Journeys

## Purpose

This document describes how each user role interacts with the Fantasy Tournament Platform throughout a season.

---

# Administrator Journey

## Phase 1 - Season Setup

Administrator logs into the platform and:

- Creates Season
- Configures season rules
- Creates Teams
- Creates Players
- Uploads team logos
- Uploads player photos
- Creates Fantasy Managers

---

## Phase 2 - Schedule Creation

Administrator:

- Creates rounds
- Creates matches
- Assigns participating teams

---

## Phase 3 - Draft Preparation

Administrator:

- Opens draft process
- Assigns players to fantasy teams
- Verifies fantasy rosters

---

## Phase 4 - Tournament Monitoring

Administrator:

- Reviews statistics
- Reviews rankings
- Corrects match data if required
- Corrects player statistics if required

---

# Scorekeeper Journey

## Match Preparation

Scorekeeper logs in and views scheduled matches.

---

## Live Match Tracking

Scorekeeper:

- Opens match
- Records goals
- Records assists
- Records saves
- Records yellow cards
- Records red cards
- Records own goals

---

## Match Completion

Scorekeeper:

- Enters final score
- Reviews recorded events
- Finalizes match

System automatically:

- Generates statistics
- Calculates fantasy points
- Updates standings

---

# Fantasy Manager Journey

## First Login

Fantasy Manager:

- Logs in
- Completes profile information
- Creates fantasy team name
- Uploads fantasy team logo

---

## Before Draft

Fantasy Manager can:

- View season information
- Wait for draft completion

Roster management is unavailable.

---

## After Draft

Fantasy Manager gains access to:

- My Team
- Schedule
- Standings
- Player Market
- Transactions
- Trades

---

## Before Round Start

Fantasy Manager can:

- Select starters
- Select bench players
- Select captain
- Save lineup
- Pickup players
- Drop players
- Create trade proposals
- Accept trades
- Reject trades

---

## Round Lock

When the round starts:

- Lineups lock
- Transfers close
- Trades close

If no lineup has been submitted, the system automatically copies the most recent valid lineup from the previous round and locks it.

---

## During Matches

Fantasy Manager can:

- View live match information
- Monitor statistics
- Track standings

---

## After Match Finalization

Fantasy Manager can:

- View updated fantasy points
- View updated rankings
- View player statistics
- Review transaction history
